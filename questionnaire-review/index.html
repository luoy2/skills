The pick you keep overriding? Make it a rule. 你总推翻的推荐，写成规则

Your overrides aren’t random. Claude Code agents ask you to decide through multiple-choice questions, with one option marked recommended. Each time you pick something else, the agent’s default judgment and yours differed. questionnaire-review finds the differences that repeat and turns them into rules you approve one by one.

你的改选不是随机的。Claude Code 的 agent 用选择题请你拍板，其中一个选项标着推荐。你每选一次别的，就说明它的默认判断和你的不一样。questionnaire-review 找出反复出现的分歧，写成候选规则，你逐条拍板。

Part of the luoy2-skills plugin · Claude Code and Codex · MIT · runs on your computer and sends nothing to the author

What you get你会得到

Your acceptance rate by kind of recommendation, themes with dated examples, and the rules you accepted. You start a round every two weeks; the first one also adds the checklist and the hook.

按推荐类型拆开的采纳率、带日期例子的主题，以及你接受的规则。每两周由你发起一轮，第一轮还会加上清单和钩子。

How it works怎么做

  1. Extract every questionnaire and your answer from ~/.claude/projects: the options, which one was recommended, what you chose or wrote instead.

    提取。从 ~/.claude/projects 取出每份问卷和你的回答：有哪些选项、推荐的是哪个、你选了什么或自己写了什么。

  2. Label. A small model labels what each recommendation does: act now, defer, keep the old path, hand you a manual step, file a ticket. The counting stays in the script.

    打标签。小模型标出每个推荐在做什么：现在就做、推迟、保持现状、让你动手、另开票。计数交给脚本。

  3. Read and audit. The agent reads every override, groups them into themes, and checks each theme against your project’s rules.

    通读、对照。agent 逐条读你的改选，归成主题，再对照项目规则，看每个主题写了没有。

  4. Decide. One question per candidate rule. Accepted rules go into your project’s rules in one PR; declined ones are skipped next round.

    拍板。每条候选规则问你一次。接受的在一个 PR 里写进项目规则，拒绝的下一轮不再提。

  5. Enforce. A PreToolUse hook hands the agent your checklist before each questionnaire, and it rewrites the question against it.

    落地。PreToolUse 钩子在每次出题前把清单交回给 agent，它先按清单改好题目再来问你。

The round wrote 6 rules and 1 hook 这一轮写进了 6 条规则和 1 个钩子

Rules reworded in general terms规则按通用措辞转述

  1. State the current situation and the mechanism before the point to decide.题干先写现状和机制，再写要裁的点。
  2. When recommending to defer, keep the old path, hand the owner a manual step or file a ticket, say why. If you can’t, recommend the other option.推荐推迟、保留旧路径、请机主动手、另开票时，写出理由；写不出来，就推荐另一边。
  3. For a structural decision, say which dimension changes and how new cases plug in.结构类决定的选项，写明哪一维变化、新情况怎么接入。
  4. Recommend one PR for changes to the same concern.同一关注点的改动，推荐放在一个 PR 里。
  5. When the same kind of problem comes up a second time, offer a structural audit as an option.同类问题第二次出现时，选项里放上结构审计。
  6. When evidence can’t be collected, first add a way to inject it; waive or split the ticket only if that fails.证据取不到时，先补上注入入口；做不到再豁免或拆票。

The hook, in one real session钩子在一次真实会话里

  1. Blocked被拦下The agent sends its first question. The hook stops it and hands back the checklist.agent 发出第一道题，钩子拦下它，把清单交回去。
  2. Rewritten按清单重写The agent rewrites the question: current state, mechanism, then the point to decide.agent 按清单把题干改成：现状、机制、要裁的点。
  3. Allowed放行The rewrite goes through 28 s after the first try.改好的题在第一次发出后 28 秒放行。

Your logs stay on your computer 日志留在你自己的电脑上

No server, no account, no telemetry, and nothing is sent to the author. A step that calls an AI model puts only what is listed below into the prompt, and sends it to the provider you chose for that step through your own claude or codex login, like any prompt you type, or through your own model gateway if you set one.

没有服务器、没有账号、没有遥测，也不向作者发送任何数据。需要调用模型的步骤，只把下面列出的内容放进提示词，用你自己的 claude 或 codex 登录发给你为这一步选的服务商，和你平时输入提示词一样；如果你设了自己的模型网关，就经过网关。
