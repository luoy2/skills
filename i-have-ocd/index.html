One main line. Everything else gets one line. 一条主线，别的记一行

Fix one bug. Get a pile of findings. Each one comes with a question: fix it now? Every detour looks cheap. Together they scatter your attention, and work that belongs together gets done piecemeal. i-have-ocd keeps one main line: a title, a done-when criterion and the next step. Everything else gets one line.

修一个 bug，报回来一堆发现。每个都问你：要不要现在修？每次岔出去看着都不贵，加起来注意力就散了，本该一起规划的活被拆得零零碎碎。i-have-ocd 只留一条主线：标题、完成标准、下一步。别的发现记一行就走。

Part of the luoy2-skills plugin · Claude Code and Codex · MIT · runs on your computer and sends nothing to the author

Fewer detours, and the side work planned together instead of piecemeal. It reads no logs and sends nothing.

How it works怎么做

  1. Every new item is sorted as main line, urgent or parked.

    每个新冒出来的事，先分成主线、紧急、停放三类。

  2. Urgent means money or position risk, a production incident, a leaked credential, or an identity check.

    紧急只有这几种：资金或持仓风险、线上事故、凭据泄露、需要你本人做的身份验证。

  3. A parked item is one line: what it is, why it matters, where it was seen. It is not fixed or asked about on the spot.

    停放就是记一行：是什么、为什么要紧、在哪儿看到的。不当场修，也不当场问。

  4. Each reply ends with one next step and a side +N count.

    每条回复都以一个下一步和 side +N 计数收尾。

  5. When you ask for a review, parked items are grouped and planned in batches, with the decisions as one set of questions.

    你要看支线时，停放的条目按领域分组、成批规划，要你决定的事一次问完。

Requirements运行要求

  • Nothing extra不需要额外工具
  • Keeps its state in one Markdown file per project under ~/.local/state/i-have-ocd/, or in focus tools if your session has them状态存在 ~/.local/state/i-have-ocd/ 下，每个项目一个 Markdown 文件；会话里有 focus 工具时就用那些工具

It reads no logs and sends nothing 不读日志，不发数据

No server, no account, no telemetry, and nothing is sent to the author. i-have-ocd works inside your conversation with the agent. It reads no logs and calls no model of its own; its state is one Markdown file on your computer, or the focus tools your session already has.

没有服务器、没有账号、没有遥测，也不向作者发送任何数据。i-have-ocd 在你和 agent 的对话里起作用：不读日志，也不自己调用模型；状态存在你电脑上的一个 Markdown 文件里，或者你会话里已有的 focus 工具里。

npx skills is Vercel’s installer. By default it reports each install (repository, skill and agent names) to skills.sh; the DISABLE_TELEMETRY=1 in the copied text turns that off. The plugin route doesn’t use it.

npx skills 是 Vercel 的安装工具，默认会向 skills.sh 报告一次安装（仓库名、skill 名、agent 名）。复制内容里的 DISABLE_TELEMETRY=1 把它关掉。插件方式不经过它。
